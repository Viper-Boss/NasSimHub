# 家卡 HomeSIM — 硬件到手验收清单

> 目标：设备到手当天，照着这份清单从零跑到完整链路，不留死角。
> 硬件：网心云 OECT（RK3566 ARM64，已刷飞牛 fnOS ARM 版）＋ 大疆 4G 模块（移远 EG25-G，大疆定制固件）。
> 逐项打勾，任何一步卡住先记录现象再继续下一项。

---

## 0. 到手先查（5 分钟）

- [ ] 模块外观：天线座（主/分集）、SIM 卡槽、USB 接口是否完好
- [ ] 放入 SIM 卡（**确认 PIN 码已关闭**：先用手机把 SIM 的 PIN 锁关掉，避免卡在模块里锁死）
- [ ] SIM 套餐确认：流量/通话余量、是否已实名激活、国际漫游开关（人在国外必查）

## 1. USB 接入 OECT：让系统认出模块

- [ ] 模块插 OECT 的 USB 口，上电
- [ ] SSH 进 fnOS，执行 `lsusb`，记录结果：
  - 大疆定制固件的 USB ID 通常是 **`2ca3:4006`** —— 系统不认，需要改成标准移远 ID
- [ ] 改 USB ID（两种方式任选其一）：
  ```bash
  # 临时（重启失效）：通过 AT 口发
  AT+QUSB="PID","0125"        # 2c7c:0125 = EC25 标准 ID
  # 或写 udev 规则把 2ca3:4006 映射为 qcserial
  ```
- [ ] 再跑 `lsusb`，确认变成 **`2c7c:0125`**
- [ ] `dmesg | tail -30`：确认出现 `qcserial`/`option` 驱动绑定的 ttyUSB*（通常 3-4 个口）
- [ ] 记下端口分配（典型）：
  - `ttyUSB0` = DM / 诊断
  - `ttyUSB1` = **GPS NMEA**
  - `ttyUSB2` = **AT 指令口** ← 主要用这个
  - `ttyUSB3` = **PPP / 语音口**

## 2. 基础 AT 验证（用 ttyUSB2，115200）

```bash
# 推荐装个简单的串口工具，或用 python -m serial.tools.miniterm
AT                          # → OK（通了）
ATI                         # → 模组标识
AT+CPIN?                    # → +CPIN: READY（SIM 就绪；SIM PIN 状态见下）
AT+CSQ                      # → 信号 10-31,0 为正常（<10 检查天线）
AT+QENG="servingcell"       # → 当前小区：制式/频段/RSRP
AT+COPS?                    # → 运营商注册状态（0,2,"CHINA MOBILE",7 = 注册上 4G）
AT+QICSGP=1,1,"CMNET"       # APN 配置（移动 CMNET / 联通 3GNET / 电信 CTNET）
AT+QIACT=1                  # 激活数据
AT+QIACT?                   # 拿到 IP = 数据通了
```

- [ ] 以上全部通过，模块基础状态 ✅

## 4. 语音验证（重点！大疆固件的生死题）

- [ ] **查固件是否带语音**：
  ```bash
  AT+QGMR                     # 看固件版本
  AT+QCFG="usbaudio"          # 语音固件才会返回 usbaudio 配置；报 ERROR = 消费版固件，无语音
  ```
- [ ] 若无语音：需要刷 EG25-G **标准商用固件**（大疆定制固件刷机有变砖风险，先备份原固件！）
- [ ] 刷机后重跑第 1 节（USB ID 可能被重置回 2c7c:0125，确认）
- [ ] 启用 USB 声卡（UAC）：
  ```bash
  AT+QCFG="usbaudio",1        # 开 UAC 声卡
  AT+CFUN=1,1                 # 重启模块生效
  ```
- [ ] OECT 上 `arecord -l`：出现 EG25-G USB Audio 设备 ✅
- [ ] 拨打测试电话：
  ```bash
  ATD13901898834;             # 注意末尾分号 = 语音呼叫（不带分号是数据呼叫）
  ```
- [ ] 本方听到对方声音（arecord 通路）✅
- [ ] 对方听到本方声音（aplay 通路）✅
- [ ] 挂断：`ATH` ✅
- [ ] 被叫测试：别的手机打进来，模块响铃 `RING` ✅，`ATA` 接听 ✅

## 4b. VoLTE 实测基线（来自 ec20-iphone-voice-sms-gateway 项目，MIT，已实机验证）

> 参考：https://github.com/XiaGuanCheShen/ec20-iphone-voice-sms-gateway/blob/main/docs/02-ec20-volte-uac.md
> 与 EG25-G 同为移远 Quectel 家族，AT 序列高度可复用。**音频路径结论：串口 PCM 优于 UAC**（UAC 实机出现过无声/电流声/爆音/重启后状态漂移——修正本清单第 4 节的假设）。

**VoLTE 开启序列（实测验证）**：

```text
AT+QCFG="ims",1                          # 期望返回 1,1
AT+QMBNCFG="AutoSel",0                   # 关闭自动选择（避免回退 GSM 的已知坑）
AT+QMBNCFG="deactivate"
AT+QMBNCFG="select","ROW_Generic_3GPP"   # 通用国际漫游 MBN 包
AT+CFUN=1,1                              # 软重启生效
```

**核验标准（不是单条 OK 就算过）**：
- AT+QMBNCFG="list" 中 ROW_Generic_3GPP 显示 selected=1 且 activated=1；
- AT+QCFG="ims" 返回 1,1；
- AT+CEREG? 返回 1（注册）或 5（漫游）；
- AT+QNWINFO 显示 LTE。

**音频走串口 PCM 的 udev 固定别名**（接口号以现场 udevadm 为准，典型：01=PCM 音频、02=AT）：

```text
/dev/ec20-audio  ←  ID_USB_INTERFACE_NUM=01
/dev/ec20-at     ←  ID_USB_INTERFACE_NUM=02
```

chan_quectel 配置要点：`audio=/dev/ec20-audio`、`data=/dev/ec20-at`、`txgain=-5`（实测降低发送电平防爆音，-4 ~ -6 微调）。**已知风险**：通话进行中收到短信可能导致模块异常（chan_quectel 底层风险），上线后需观察。

## 7. 已知坑（按概率排序）

| 坑 | 现象 | 解法 |
|----|------|------|
| 大疆 USB ID | `lsusb` 是 2ca3:4006，无 ttyUSB | `AT+QUSB="PID","0125"` 或 udev 映射 |
| 消费版固件无语音 | `AT+QCFG="usbaudio"` 报 ERROR | 刷 EG25-G 标准商用固件（先备份） |
| UAC 没起来 | 刷完语音固件仍无声卡 | `AT+QCFG="usbaudio",1` + `AT+CFUN=1,1` |
| SIM PIN 锁 | `AT+CPIN?` 返回 SIM PIN | 先在手机上关闭 PIN 再插卡 |
| 语音口占用 | 拨号报 NO CARRIER | 检查 pppd 是否占了 ttyUSB3 |
| 双模组 | 第二个模块端口混淆 | 系统页「模块管理」里核对 IMEI 对应关系 |
